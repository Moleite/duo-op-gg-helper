# DOM selectors of the site

> **Answers**: which selector reads which data of the site
> **Does not answer**: repairing after a site update → [`../architecture/dom-selectors.md`](../architecture/dom-selectors.md)

Generated by `scripts/generate.mjs` from `extension/src/data/selectors.js`. Do not edit this file: change the source, then run `npm run gen`.

| Key | Selector | Targets |
| --- | -------- | ------- |
| `row` | `li.MuiCollapse-root` | Row of the post table (an <li> element that React manages). |
| `rowAnchor` | `div[id^="partner-"]` | Block of the row that carries the post id: `partner-<id>`, the same id as in the API. |
| `list` | `ul` | Parent list of the rows. Found from a row with closest(), never alone. |
| `summonerLink` | `a[href*="/summoners/"]` | op.gg link of the player: text = gameName, href = /summoners/<region>/<gameName>-<tagLine>. |
| `tagLine` | `div.text-3xs.text-gray-500` | Line under the name: `#<tagLine>`, then ` / Verified` for a verified account. |
| `verified` | `img[alt="Verified"]` | Riot badge of a verified account. |
| `position` | `svg.position-icon:not(.looking-for)[aria-label]` | Played position: aria-label Top, Jungle, Mid, ADC, Support or All Positions. |
| `lookingFor` | `svg.position-icon.looking-for[aria-label]` | Wanted positions. The site shows two at most. |
| `lookingForMore` | `span.text-gray-400` | Text `+` after the wanted position icons: the shown list is truncated. |
| `rankCode` | `span.text-2xs.whitespace-nowrap` | Rank code: E2, M1, UR (unranked). |
| `winRateBlock` | `div.w-38` | Win rate cell: spans `140W`, `136L` and the overall percentage `51%`. |
| `champion` | `div.w-36 img[alt]` | Recent champion: alt = name. The next span holds its win rate, the tooltip its games. |
| `kda` | `div.w-20.text-3xs` | KDA cell: average `9.7 / 8.1 / 6.7`, then the ratio in div.leading-4. |
| `opScore` | `div.w-16.text-3xs` | OpScore cell. div.w-16 alone also matches the position cell. |
| `note` | `[id$="-edit-note"]` | Note of the post: full text in aria-label. |
| `posted` | `div[title] p` | Age: `20 mins ago`, `3 hrs ago`, `a day ago`. The title of the parent is a 12-hour time without AM or PM. |
| `accountName` | `[class*="DesktopGNB-module_user-btn"] [class*="DesktopGNB-module_text"]` | Name of the signed-in op.gg account, in the site header. Absent when signed out. |
| `filterPosition` | `ul.filters__position li.selected` | Active native position filter: attribute value (ALL, TOP, JUNGLE, MID, BOTTOM, SUPPORT). |
| `filterQueue` | `select[name="queue_type"]` | Native queue: RANKED_SOLO, RANKED_FLEX, ARAM... |
| `filterTier` | `select[name="tier"]` | Native tier: ALL, UNRANKED, IRON... CHALLENGER. |
| `filterRegion` | `input.MuiSelect-nativeInput` | Native region (value `euw`). Fallback: region parameter of the URL. |
| `postButton` | `button` + text `Post & find Duo` | Button of the site that opens the post form. Found by its text. |
