# Version 1 and the move to v2

> **Answers**: what the v1 did · where to find it · what each feature of the v1 became in v2 · importing the v1 blacklist.
> **Does not answer**: the details of the v2 rules → [`../filters/rules.md`](../filters/rules.md)

The v1 (manifest `1.0`) is the original extension, imported on `main` with the tag `v1.0`. Only `blacklist.txt` differs from the original: it keeps its header, and the names stay out of the public repository. The v2 replaces the v1 at the root of the repository with the `extension/` folder.

## What the v1 did

- A popup: position, tier, division, minimum win rate, Filter button.
- An injected script (`injects/inject_filter.js`) that deleted the filtered rows of the table.
- A blacklist in `blacklist.txt`, shipped in the extension: one name per line, `# note` at the end of the line.
- Badges at the top right of the page, one per deletion reason.
- The `<all_urls>` permission and on-demand injection.

## Mapping

| v1 | v2 |
| -- | -- |
| rows deleted (`li.remove()`) | rows hidden or dimmed, reasons shown ([`../architecture/panel.md`](../architecture/panel.md#hiding-dimming-sorting)) |
| Filter popup, one click per filtering | panel on the page, recompute at each change of the table |
| `blacklist.txt` in the package | blacklist per player, local and in Neon, ⛔ button on each row |
| counting badges | one counter per rule in the panel |
| position, rank, win rate, duplicate and looking-for filters | same rules, plus minimum games, maximum age, hiding by hand |
| 50 posts of the site | Show more, through the API of the site ([`../architecture/site-api.md`](../architecture/site-api.md)) |
| `<all_urls>` | `https://duo.op.gg/*` and `https://*.neon.tech/*` |

## Intended behavior changes

- Unreadable rank: the v1 deleted the row, the v2 keeps it.
- Win rate at zero games: the v1 read 0 %, the v2 reads no value.
- Duplicates: the v1 compared the name alone, the v2 compares the name and the tag.
- The rank compatibility table is the one of the v1, unchanged ([`../filters/ranks.md`](../filters/ranks.md)).

## Importing the v1 blacklist

1. Open the old `blacklist.txt`.
2. Popup, Blacklist tab: paste the content, then click Import.

The format is accepted as it is: `#` lines ignored, note after ` #`. The names without a tag match every tag of the name. `src: extension/src/ui/popup-blacklist.js#function parseList(text)`

⚠️ The v1 blacklist holds names and comments about other players. It does not go into the repository, which is public. It goes into Neon, where RLS keeps it to its owner.

## Finding the v1

```bash
git checkout v1.0      # then load the root of the repository in chrome://extensions
git checkout main
```
